## Lab Activity 1A: Discussion

In this activity, I integrated the Image area into the `newsfeed_card.dart` using a conditional widget. I used the `hasImage` variable to determine whether an image should be displayed or not.

If `hasImage` is true, the image placeholder will appear. If it is false, the image area will not be displayed. This makes the newsfeed card dynamic because it can show posts with or without images.

I also customized the user avatar and used widget-based Like and Comment buttons to improve the appearance of the newsfeed.
